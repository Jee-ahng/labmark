        视频库

        标注数据按视频分开保存，切换不会互相影响

          添加视频 每行一个，可写「名称 VID」，也能只粘 VID
          VID 在保利威后台 → 点播 → 视频列表里复制，一般以 _0 / _8 结尾

          为什么不能自动列出账号下的全部视频？保利威的点播列表接口要用 secretkey 签名， 把 secretkey 写进前端等于公开泄露，接口也不允许浏览器跨域直连。
          LabMark 是纯前端、无后端，所以这里是「本地视频库」—— 登记过的 VID 存在本机浏览器里，下次打开还在。

          AI 设置

          支持任意 OpenAI 兼容接口，配置只保存在本机浏览器

          提示：key 写在前端仅适合本地 / 比赛演示。若识帧报「不支持图片」，请改填多模态模型。
